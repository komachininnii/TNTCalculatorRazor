# 用語集（BMR・体重関連）

保守時に混同しやすい語彙のみを定義する。

## 体重系

- **ActualWeight（実測体重）**
  - 入力された実体重。BMR算出などで使用。

- **StandardWeight（標準体重）**
  - 年齢/身長/性別から求める基準体重。肥満度や一部計算の基準。

- **AdjustedWeight（調整体重）**
  - 肥満時に実測体重を補正した体重。

- **CorrectedWeight（採用体重）**
  - 実測/標準/調整の中から、計算条件に応じて最終採用された体重。

## BMR・エネルギー系

- **ActualBMR**
  - 実測体重ベースの基礎代謝量（「基礎代謝量」表示はこれを指す）。

- **CorrectedBMR based energy**
  - 採用体重ベースBMRに係数を適用した必要エネルギー算出系。

## 値の区分

- **Raw**: 未丸め内部値
- **Final**: 丸め確定値
- **Display**: 表示専用値

## 実装・保守ルール

- 用語の詳細な式や分岐は現行コードを正とする。
- 命名を変更する場合は、UI表記・Modelプロパティ名・テスト名を同時に点検する。
