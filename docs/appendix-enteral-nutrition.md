# 経腸栄養の計算仕様

## 概要

本アプリケーションでは、様々な経腸栄養剤の投与量計算に対応しています。
理論値（kcal/mL）ではなく、**実製剤のパッケージ規格に合わせた計算**を行うことで、
現場での準備作業を効率化しています。

---

## 投与量の計算方法

### 基本方針

実製剤のパッケージ規格を基準とした換算係数を使用します。

**理由**：
- 規格単位の割付（本数計算）と整合しやすい
- 在庫管理が効率的
- 現場の準備が容易

### 複数規格がある場合

同一製剤に複数の規格（パッケージサイズ）がある場合、
**大きい方の規格を計算基準**とします。

**例**：1.5倍濃度の製剤
```
規格A：200 mL（300 kcal）
規格B：267 mL（400 kcal）← こちらを基準に採用

計算基準：267 mL / 400 kcal = 0.6675 mL/kcal
```

### 計算例

**必要エネルギー**：1099 kcal

**投与量計算**：
```
1099 kcal × (267/400) ≒ 733.58 mL → 734 mL（四捨五入）
```

**割付候補**：
```
267 mL × 2本 = 534 mL（800 kcal）
200 mL × 1本 = 200 mL（300 kcal）
───────────────────────────────
合計：734 mL（1100 kcal）
```

**結果**：端数なしで割付完了

---

## 丸め誤差について

実製剤のパッケージ規格（割付）と、mL/kcal の換算・丸め（四捨五入）により、
必要エネルギー（計算値）と実投与カロリー（製剤ベース）に差が生じることがあります。

**例**：
- 必要エネルギー：1099 kcal（計算値）
- 実投与カロリー：1100 kcal（製剤ベース）
- 差分：+1 kcal

この差は：
- パッケージ規格と丸め仕様による構造的なもの
- アプリ上は差が分かるように表示する
- 差の解釈は施設の運用・臨床判断に従う

### 丸め仕様
- kcal：四捨五入（0.5は切り上げ）
- g（1桁）：四捨五入（0.05は切り上げ）
- 水分mL：切り上げ
- 経腸mL：四捨五入（0.5は切り上げ）

---

## 実装

### データ構造

各製剤の換算係数は「1 kcal あたりの比率」で定義しています：
```csharp
// 例：1.5倍製剤（267 mL / 400 kcal）
VolumePerKcal = 267.0 / 400.0   // mL/kcal
ProteinPerKcal = 14.0 / 400.0   // g/kcal
FatPerKcal = 16.0 / 400.0       // g/kcal
// ...
```

### 設計意図

**kcal 基準を採用した理由**：
1. **必要エネルギー（kcal）から投与量（mL）への換算が明確**で、割付候補の提示と整合しやすい
2. **添付文書との対応**：製剤の成分表は「○○ kcal あたり」で記載されている
3. **データ入力の容易性**：添付文書の数値をそのまま転記しやすい
4. **保守性**：成分変更時の更新が簡単
5. **可読性**：テーブル定義が直感的
6. **精度の考え方**：mL 基準も検討したが、実運用上の差は小さいため（製剤のばらつき等も踏まえ）kcal 基準を採用

## 新製剤の追加

新しい経腸栄養剤を追加する場合：

1. 製剤の規格を確認（パッケージサイズとカロリー）
2. 複数規格がある場合、大きい方を基準に選択
3. 添付文書から成分を転記
4. 製剤テーブル：`Domain/Tables/EnteralFormulaTable`
5. 製剤規格：`Domain/Tables/EnteralPackageTable`
1. 製剤種類：`Domain/Enums/EnteralFormulaType`
5. テスト：`TestData/EnteralFormulaTestCases`
