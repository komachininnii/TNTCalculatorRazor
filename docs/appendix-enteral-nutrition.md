# 経腸栄養の計算仕様

## 概要

本アプリケーションでは、様々な経腸栄養剤の投与量計算に対応しています。
理論値（kcal/mL）ではなく、**実製剤のパッケージ規格に合わせた計算**を行うことで、
現場での準備作業を効率化しています。

---

## 投与量の計算方法

### 基本方針

実製剤のパッケージ規格を基準とした換算係数を使用します。

**理由**：
- 割付候補で端数が出にくい
- 在庫管理が効率的
- 現場の準備が容易

### 複数規格がある場合

同一製剤に複数の規格（パッケージサイズ）がある場合、
**大きい方（高カロリー側）の規格を計算基準**とします。

**例**：1.5倍濃度の製剤
```
規格A：200 mL（300 kcal）
規格B：267 mL（400 kcal）← こちらを基準に採用

計算基準：267 mL / 400 kcal = 0.6675 mL/kcal
```

### 計算例

**必要エネルギー**：1099 kcal

**投与量計算**：
```
1099 kcal × (267/400) = 733.58 mL → 734 mL（四捨五入）
```

**割付候補**：
```
267 mL × 2本 = 534 mL（800 kcal）
200 mL × 1本 = 200 mL（300 kcal）
───────────────────────────────
合計：734 mL（1100 kcal）
```

**結果**：端数なしで割付完了

---

## 丸め誤差について

実製剤のパッケージ制約により、必要エネルギーと実投与カロリーに
わずかな差（通常 ±1〜2 kcal）が生じることがあります。

**例**：
- 必要エネルギー：1099 kcal（計算値）
- 実投与カロリー：1100 kcal（製剤ベース）
- 差分：+1 kcal

この差は：
- パッケージ規格による構造的なもの
- 医療的に許容範囲内
- ユーザーに透明に表示

---

## 実装

### データ構造

各製剤の換算係数は「1 kcal あたりの比率」で定義しています：
```csharp
// 例：1.5倍製剤（267 mL / 400 kcal）
VolumePerKcal = 267.0 / 400.0   // mL/kcal
ProteinPerKcal = 14.0 / 400.0   // g/kcal
FatPerKcal = 16.0 / 400.0       // g/kcal
// ...
```

### 設計意図

**kcal 基準を採用した理由**：
1. **計算の正確性と割付の最適化**：必要エネルギー（kcal）から投与量（mL）への換算が誤差なく行え、
   大きい規格の製剤を基準とすることで割付時の端数が出にくい
2. **添付文書との対応**：製剤の成分表は「○○ kcal あたり」で記載されている
3. **データ入力の容易性**：添付文書の数値をそのまま転記可能
4. **保守性**：成分変更時の更新が簡単
5. **可読性**：テーブル定義が直感的
6. **精度の検討**：mL 基準も検討したが、得られる精度向上（0.01 g レベル）は製剤のロット間ばらつき
  （±10%）に比べて無視できると判断

---

## 新製剤の追加

新しい経腸栄養剤を追加する場合：

1. 製剤の規格を確認（パッケージサイズとカロリー）
2. 複数規格がある場合、大きい方を基準に選択
3. 添付文書から成分を転記
4. `EnteralFormulaTable` に定義を追加
