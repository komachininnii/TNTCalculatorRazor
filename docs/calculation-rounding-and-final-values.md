# 計算結果の丸め仕様と Final 値

本書は、現行実装での丸め仕様を保守向けに簡潔化したもの。

## 基本原則

- `Raw`: 未丸めの内部計算値
- `Final`: 仕様として確定した値（丸め適用後）
- `Display`: 画面表示専用

> 丸めは `RoundingRules` に集約し、表示都合で再丸めしない。

## 現行の丸め規則

- エネルギー（kcal）: 四捨五入（0.5切り上げ）
- 蛋白（g）: 小数1桁で四捨五入（0.05切り上げ）
- 水分（mL）: 切り上げ
- 経腸栄養量（mL）: 四捨五入（0.5切り上げ）

## 運用上の注意

- 計算の正しさは `Final` を基準に評価する。
- 表示フォーマット変更は、計算結果（`Final`）に影響させない。
- 丸め仕様を変更する場合は、`RoundingRules` と関連テストを同時更新する。
